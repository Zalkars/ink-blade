# Ink Blade: общий Godot-проект для Windows и Android

## Решение

Порт строится как один проект Godot 4.x. Из него будут экспортироваться две
сборки:

- Windows — для разработки, клавиатуры и геймпада;
- Android — для сенсорного управления и мобильного рендера.

Исходную Windows-версию в `InkBladeWin` не изменяем. Она остаётся рабочим
эталоном поведения до тех пор, пока Godot-версия не достигнет паритета.

## Почему GDScript для общего проекта

Игровой код в текущем репозитории написан на C#, но отрисовка жёстко связана
с WinForms/SkiaSharp, звук — с NAudio, а ввод — с Windows XInput. Эти части
всё равно нужно заменить на кроссплатформенные подсистемы Godot.

GDScript позволяет сразу использовать стандартные Android/Windows export
templates и Godot API без привязки к WinForms. Игровые правила и данные будут
общими, а платформенные различия ограничатся вводом, звуком, настройками
экспорта и небольшими элементами UI.

## Структура (реализована)

```text
godot/
  project.godot        # GL Compatibility, 1280×720, sensor_landscape
  main.tscn            # единственная сцена -> scripts/game.gd
  scripts/
    ink.gd             # InkR — чернильный рендер (порт Ink.cs)
    world.gd           # InkWorld — физика и зал (порт World.cs)
    player.gd          # InkPlayer (порт Player.cs)
    enemy_base.gd, grunt.gd, sentry.gd, dummy.gd, enemy_bolt.gd
    fx.gd              # InkFx (порт Fx.cs)
    hud.gd             # InkHud (порт Hud.cs)
    game.gd            # оркестратор (порт Game.cs)
    input_ink.gd       # автолоад CTL (порт Input.cs; клавиатура/геймпад/тач)
    audio_ink.gd       # автолоад SND (порт Audio.cs; AudioStreamGenerator)
    bake_node.gd       # запекание статики через SubViewport
  assets/icon.svg
```

Основное разрешение 1280×720 с масштабированием `aspect=ignore`, ориентация
landscape (sensor_landscape на Android). Холст заполняет весь экран телефона без
боковых рамок. Тач-слой `game.gd` рисует плавающий стик и
кнопки A X B Y Ⅱ, поддерживает multi-touch и принимает тапы в меню, паузе и
на экране смерти. Координаты касаний переводятся через canvas transform, так
что раскладка сохраняется на телефонах с разным aspect ratio. Действия игры те
же, что и на Windows: move, jump, attack, dash, heal, pause, restart.

## Текущее состояние

Порт завершён до уровня прототипа-эталона: весь игровой код оригинала перенесён —
титульный экран, тестовая комната, игрок, три типа противников, снаряды,
атака/пого/дефлект, рывок, лечение, комбо, хитстоп, hazard-телепорт,
пауза (в т.ч. экран управления), экран смерти, отладочные хитбоксы,
сенсорные кнопки, полный экран (F11) и скриншоты (F12). Рендер и звук работают
без внешних ресурсов (синтез).

## Альтернатива

Если принципиально сохранить максимум C#-кода, можно выбрать MonoGame. Он
официально поддерживает Android, но потребует собственного слоя примитивов,
UI, touch input и аудио. Godot C# тоже возможен, однако Android-экспорт C# в
документации Godot помечен как experimental, поэтому для первого общего
проекта выбран GDScript.
