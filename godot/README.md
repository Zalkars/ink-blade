# Godot-порт

Откройте эту папку в Godot 4.5.1 или новее и запустите `main.tscn`.

Проект использует Compatibility renderer, внутреннее разрешение 1280×720 и
landscape-ориентацию. На Windows доступны клавиатура и геймпад; на Android
включаются сенсорные кнопки в нижней части экрана.

Пока Android SDK не настроен, проект можно запускать в редакторе и собирать
под Windows. Готовые пресеты находятся в `export_presets.cfg`: Windows и
Android arm64 debug APK. Для публикации в магазине понадобится отдельный
release keystore и переключение формата экспорта на AAB.
