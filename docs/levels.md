# Уровни — как устроены и как править

**Статус:** работает: `ch01_hall` (срез), `arena_01` (старая тестовая зала)
**Связано:** `docs/content-schema.md` §5

---

## 1. Файлы

| Файл | Что |
|---|---|
| `content/levels/<id>.json` | данные уровня |
| `scenes/level/<id>.tscn` | сцена с `data_path` на JSON |
| `scripts/world/level.gd` | загрузка, тайлы, враги, чекпоинты |
| `scripts/world/ink_tileset.gd` | тайлсет и коллизии |
| `tools/build_tileset.gd` | перерисовка атласа |

Новый уровень = JSON + сцена + строка в `LEVELS` в `game_flow.gd`. Код уровня при этом не меняется.

---

## 2. Сетка

- Тайл 32×32.
- Все координаты геометрии и чекпоинтов кратны 32.
- Прямоугольники задаются верхним левым углом: `x, y, w, h`.
- `solids` — твёрдые блоки, `one_ways` — платформы, сквозь которые можно прыгнуть снизу.
- Верхний ряд блока рисуется тайлом с рваной кромкой, остальное — заливкой.

Координаты врагов и чекпоинтов — **по ногам**: существо ставится так, чтобы стоять на указанной линии.

---

## 3. Пределы прыжка

Текущий контроллер:

| Параметр | Значение |
|---|---|
| Высота прыжка | ~142 px (4 тайла с запасом 14 px) |
| Дальность прыжка | ~232 px |
| Длина рывка | ~147 px |

Практические правила:

- Подъём между площадками — не больше **96 px** (3 тайла), чтобы оставался запас.
- Горизонтальный разрыв — не больше **160 px**.
- Ям без дна нет: игрок не умирает от падения, поэтому нижний уровень должен быть всегда.

## 4. `ch01_hall` — уровень среза

Ширина 6016 px (188 тайлов), высота 720.

| Зона | X | Что внутри |
|---|---|---|
| Порог | 0–1280 | вход, первые ползуны, чекпоинт `cp_01` |
| Архив | 1280–3200 | платформы, нижняя ниша, чекпоинт `cp_02` |
| Галерея имён | 3200–4992 | столбы и платформы, чекпоинт `cp_03` |
| Зал Первого Взмаха | 4992–6016 | арена, чекпоинт `cp_04` |

Чекпоинты: `cp_01` (128, 576), `cp_02` (2016, 640), `cp_03` (3488, 576), `cp_04` (5088, 576).

Враги: 12 ползунов, ID `e1`…`e12`. Позже часть заменится часовыми, кляксами и боссом; ID сохраняются, чтобы старые сохранения не ломались.

## 5. Проверка

- Smoke: `Godot --headless --path godot res://tests/smoke.tscn`.
- Тест проверяет число врагов и чекпоинтов, ширину уровня, границы камеры и клетки тайлов.
- Глазами: `Godot --path godot res://tests/capture.tscn` — снимет кадры в `%TEMP%\opencode`.
