# Чернильный клинок v0.1 — тестовая зала

Первый native-прототип на Windows: одна тестовая комната для утверждения
визуала, управления и боя.

## В сборке

- Рисованный чернильный стиль: бумага, туши, кровавые акценты, свечи и виньетка.
- Полное управление с клавиатуры и геймпада.
- Перемещение, прыжок, рывок с неуязвимостью, лёгкая и тяжёлая атака,
  воздушный отскок от врага, лечение за душу.
- Манекен, два наземных врага, летающий часовой, яма с шипами и платформы.
- HUD, пауза, экран управления, смерть и возрождение.
- Синтезированный звук без внешних аудиофайлов.
- Self-contained Windows x64 build: .NET устанавливать не нужно.

## Запуск

1. Скачайте `InkBlade-win-x64.zip`.
2. Распакуйте архив.
3. Запустите `InkBlade.exe`.

## Управление

`A/D` — движение, `Пробел/Z` — прыжок, `J/X` — атака, `K/Shift` — рывок,
`L/V` — лечение, `Esc/Enter` — пауза, `F1` — управление, `F11` — полный экран.

## Ограничения

Это не полная игра, а тестовая зала. Уровней, метапрогрессии и переназначения
клавиш пока нет.
