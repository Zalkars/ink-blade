# Сохранения — схема и правила

**Статус:** работает в каркасе: автосейв, чекпоинт, память об убитых врагах
**Связано:** `docs/tech-brief.md` §11

---

## 1. Где лежат

```
user://saves/auto.json       — автосейв (пока единственный рабочий слот)
user://saves/auto.json.bak   — предыдущая версия, если запись уже была
user://saves/<slot>.json     — ручные слоты, зарезервировано под меню профиля
```

`user://` на Windows — `%APPDATA%\Godot\app_userdata\Ink Blade`. Формат — JSON, чтобы сохранение можно было прочитать глазами и починить руками.

Запись атомарная: сначала `auto.json.tmp`, потом переименование поверх `auto.json`, старая версия уходит в `.bak`. Если игра упадёт посреди записи, целым останется либо старый, либо новый файл, но не «половина».

---

## 2. Схема

```json
{
  "version": 2,
  "saved_at": 1762300000,
  "level": "ch01_hall",
  "checkpoint": "cp_mid",
  "killed": ["e1", "e3"],
  "hp": 5,
  "enemies_left": 2,
  "cleared": false
}
```

| Поле | Что значит |
|---|---|
| `version` | Версия схемы. Если сейв новее игры — предупреждение, а не краш |
| `saved_at` | Unix-время записи |
| `level` | ID уровня |
| `checkpoint` | ID пройденного чекпоинта, `""` — точка входа |
| `killed` | ID спавнов, которых уже нет в мире |
| `hp` | Здоровье на момент записи |
| `enemies_left` | Сколько врагов осталось (для отладки и будущего экрана слотов) |
| `cleared` | Уровень пройден |

Версия 1 (до чекпоинтов) читается: `SaveGame.migrate()` добавляет `checkpoint` и `killed` со значениями по умолчанию.

---

## 3. Когда пишется

- старт уровня;
- касание чекпоинта (игрок лечится до полного);
- смерть врага;
- зачистка уровня.

Ручного сохранения пока нет: оно появится вместе с меню слотов.

---

## 4. Что помнит мир

Пока только две вещи:

1. **Чекпоинт** — где появляться после смерти.
2. **Убитые враги** — они не возрождаются после смерти игрока.

Позиция игрока внутри уровня, подобранные предметы, открытые двери и флаги диалогов появятся вместе с вертикальным срезом. Для них уже есть место: `killed` — это первый список такого рода, остальные добавятся рядом.

---

## 5. Смерть и продолжение

- Смерть → окно «Вы погибли» → «С чекпоинта» читает автосейв и собирает уровень заново.
- «Заново» в паузе начинает уровень с начала и перезаписывает автосейв.
- На титуле пункт «Продолжить» появляется, только если автосейв существует и уровень не зачищен.
- Зачищенный уровень не продолжается с середины: «Продолжить» начнёт новый заход.

---

## 6. Чего ещё нет

- Меню ручных слотов и профилей.
- Отдельное «состояние мира» для предметов, дверей и диалогов.
- Проверка контрольной суммы и защита от ручной правки файла.
- Синхронизация с облаком.
