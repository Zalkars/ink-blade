# ADR 0004. GL Compatibility на Windows и Android

Обе платформы используют GL Compatibility. Проект рисует чернильные контуры, частицы и запечённый фон на общем пути рендера. Настройки проекта и оба пресета экспорта проверяются при изменениях графики. Новые эффекты должны работать с этим рендерером на обеих платформах.

Это решение заменяет [ADR 0002](0002-dual-renderer.md).
