# Ощущения — эталон

Заполняется автором проекта. Короткие ответы, без терминов.

## Прыжок

- С места долетаю до: __________
- С разбега: __________
- Кажется: высоким / низким / нормальным
- Зажатие даёт больше высоты? да / нет

## Рывок

- Дистанция: __________
- Ощущается: резким / плавным / вялым
- В воздухе: нужен / не нужен

## Бег

- До максимальной скорости: почти сразу / с разгоном
- Торможение: резкое / скользит

## Атака

- Отзывчивость: сразу / с задержкой
- Серия: связывается / рвётся
- Отмена рывком: работает / нет
- Pogo: получается / нет

## Урон и смерть

- Хитстоп: ощущается / нет
- Неуязвимость после урона: хватает / мало

## Общее

- Что нравится больше всего: __________
- Что раздражает: __________
- Что обязательно сохранить при переезде: __________
